# BikeShare
Code for the Kaggle Bike Share Competition

The competition can be found here: [https://www.kaggle.com/competitions/bike-sharing-demand]. The purpose of the competition was to forecast use of a city bikeshare system
I attempted various methods: logistic and penalized regression, random forest, SVM, BART, XGBoost, and MLP. Ultimately, BART performed the best in this competition with a score of 0.40779.
